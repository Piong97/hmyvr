ABOUT THE PROJECT

Preserving history.
Inspiring discovery.

Haji Mohammad Yassin – VR is a digital exploration project dedicated to bringing the mosque's architectural character into an accessible, interactive environment.

Through 3D visualization, a curated gallery, and augmented reality, visitors can discover the mosque from wherever they are. This is a project introduction; historical details can be added once verified.
